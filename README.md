# SuperMed Help Center

A [Docusaurus](https://docusaurus.io/) documentation/FAQ site with [Pagefind](https://pagefind.app/) search — an **unofficial** demo wiki styled after [SuperMed](https://supermed.ro) (dark/starfield theme, Inter font, blue-cyan gradient accents). The content walks through a physician configuring their clinic (video visits, scheduling, patient records, billing, HIPAA compliance, etc.). Not affiliated with or endorsed by SuperMed.

## Requirements

- Node.js 20+

## Local development

```bash
npm install
npm start
```

This starts a hot-reloading dev server at `http://localhost:3000/wiki-demo/`.

> **Note on search in dev mode:** Pagefind indexes the final static build, not the dev server, so the `/search` page will show a "search index not found" message under `npm start`. To try search locally, build and serve the production site instead (below).

## Production build + search index

```bash
npm run build
```

`npm run build` runs `docusaurus build` and then automatically runs `pagefind --site build --output-subdir pagefind` as a `postbuild` step, generating a search index at `build/pagefind/`. The `/search` page (`src/pages/search.js`) loads `pagefind-ui` client-side from that folder.

To try the fully built site, including search, locally:

```bash
npm run build
npm run serve
```

## Deploying to GitHub Pages

`docusaurus.config.js` is already pointed at `andrast0th/wiki-demo` (`url`, `baseUrl`, `organizationName`, `projectName`, and the GitHub links). If you fork this to a different account/repo, update those values first.

### Option A — GitHub Actions (recommended)

This repo includes [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml), which builds the site (including the Pagefind index) and deploys it using GitHub's official Pages Actions on every push to `main`.

1. Push this repo to GitHub.
2. In the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the **Actions** tab). The site will be published at `https://andrast0th.github.io/wiki-demo/`.

### Option B — `docusaurus deploy` (classic `gh-pages` branch)

```bash
GIT_USER=andrast0th npm run deploy
```

This builds the site (including the Pagefind postbuild step) and pushes the `build/` output to a `gh-pages` branch using [`docusaurus deploy`](https://docusaurus.io/docs/deployment#deploying-to-github-pages). If you use this option, set **Settings → Pages → Source** to **Deploy from a branch → `gh-pages`** instead of GitHub Actions.

## Project structure

```
docs/                    Documentation & FAQ content (Markdown)
  getting-started/
  video-consultations/
  scheduling/
  patient-management/
  billing/
  security-compliance/
  faq/
src/
  pages/
    index.js             Homepage
    search.js            Pagefind-powered search page
  components/
    HomepageFeatures/
  css/custom.css          Theme colors + Pagefind UI theming
static/                   Static assets (favicon, logo, etc.)
docusaurus.config.js       Site config, navbar, footer
sidebars.js                 Docs sidebar (autogenerated from docs/ folder structure)
.github/workflows/deploy.yml  GitHub Actions deploy to GitHub Pages
```

Docs content (the clinic, "Dr. Osei", specific UI copy, plan names, etc.) is invented for demo purposes. The visual style is modeled on the real [supermed.ro](https://supermed.ro), but this site is unofficial and not affiliated with or endorsed by SuperMed.
